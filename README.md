# 🔥 AI-Based Fire and Smoke Detection with Uncertainty-Aware Smart Surveillance System

An AI-powered smart surveillance system that detects fire and smoke in real time using YOLOv8, Flask, OpenCV, and Python.  
The system also analyzes prediction confidence and identifies uncertain detections to improve reliability and reduce false alarms.

---

# 🚀 Features

✅ Real-time Fire Detection  
✅ Real-time Smoke Detection  
✅ AI Uncertainty Detection  
✅ Confidence Level Monitoring  
✅ Live Webcam Dashboard  
✅ Smart Alert System  
✅ Screenshot Saving  
✅ Detection History  
✅ Modern CCTV-Style Dashboard UI  

---

# 🧠 Core Innovation

Traditional AI systems make predictions even when they are uncertain.  
This project improves fire and smoke detection by identifying uncertain predictions and alerting users for verification, making AI systems safer and more reliable.
